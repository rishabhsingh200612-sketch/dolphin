# ❤️ Proposal Website — Setup Guide

## 1. Edit your details
Open **script.js**, and edit only the section at the top marked:

```js
// ========================================
// ❤️ EDIT ONLY THIS SECTION
// ========================================
```

Fill in:
- `girlfriendName` — her name
- `instagramReels` — paste Instagram Reel links
- `instagramPosts` — paste Instagram photo/post links
- `photos` — filenames of photos you've placed in the `assets/` folder
- `music` — filename of your background song in `assets/`
- `whatsappNumber` — your WhatsApp number with country code, no `+` or spaces
- `whatsappMessage` — the message that's pre-filled when she messages you

## 2. Add your files
Drop your photos and mp3 into the `assets/` folder (see `assets/README.txt`).

## 3. Open it
Just double-click `index.html` — no server or install needed.

**Note on Instagram embeds:** the site uses Instagram's own official embed
script, so it works exactly like embedding on any normal website. If a
specific link can't be embedded (private accounts, certain content types,
or if Instagram blocks it in her browser), the site automatically shows a
pretty "Watch This On Instagram" card that opens the real link instead —
nothing is faked.

## 4. Best experience
This was built mobile-first — send her the `index.html` (hosted somewhere
like GitHub Pages, Netlify, or Vercel — all free) so she can open it on her
phone. Desktop and tablet look great too.

Good luck 🥹❤️💍
